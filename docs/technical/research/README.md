# Research boundary

[Technical manual](../README.md) / Research boundary

This public repository starts with source, not the earlier private Git history,
captures, machine inventory, issue/session links, run ledgers or superseded
design plans. Those original records remain private and unchanged. They are
not redirected to nonexistent commits or runs in this repository.

The [qualification summary](../QUALIFICATION.md) retains bounded earlier
observations and their limits, including the receiver-first teardown followed
by a Labs crash and the later source-first reset with actual exit 9.
Neither establishes general teardown safety or qualifies the public bootstrap.

## Frozen probe

The [Labs research probe](../../../tools/research/labs-probe/README.md) is retained
as source and invented regression fixtures only. It remains **STOP / DO NOT
RERUN**. Building or testing it is not permission for a live trial, capture,
configuration change or simulator operation.

## Installer and automation records

The [installer manual](../INSTALLER.md), [automation guide](../AUTOMATION.md),
and [command reference](../COMMANDS.md) describe the current implementation.
Installer qualification remains parked and separately authorized; its retained
private-repository gate is intentionally not relaxed for the public home.
Old failed results are not relabeled by later success or by this migration.
